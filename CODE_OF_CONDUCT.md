# Code of Conduct

We want this project to be welcoming, respectful and useful to everyone, regardless of experience level,
background, language or identity.

**Expected:** be kind and patient; give and accept feedback constructively; assume good intent; stay on topic;
help newcomers.

**Not acceptable:** harassment, insults, discrimination, personal attacks, publishing others' private information,
and using the project to plan or carry out fraud or other harm.

Maintainers may edit, remove or reject contributions, and may restrict participation, to uphold these standards.
To report a problem, contact the maintainers through GitHub (a private message or a private security advisory,
if the matter is sensitive).

This Code of Conduct is inspired by the Contributor Covenant.
